# Delivering data from a Yandex Managed Service for Apache Kafka® queue to Yandex MPP Analytics for PostgreSQL through Yandex Data Transfer

With [Data Transfer](https://yandex.cloud/en/docs/data-transfer), you can deliver data from a [Managed Service for Apache Kafka®](https://yandex.cloud/en/docs/managed-kafka) cluster to a [Yandex MPP Analytics for PostgreSQL](https://yandex.cloud/en/docs/managed-greenplum) one. See [this tutorial](https://yandex.cloud/en/docs/data-transfer/tutorials/managed-kafka-to-greenplum) to learn how to set up the solution with Terraform. This repository contains the configuration file you will need: [kafka-greenplum.tf](kafka-greenplum.tf).
